# Sales & Trading Interview Prep + Black-Scholes Course

A daily study system for getting back into trading and interviewing for sales & trading roles.

## What you get every day

Each day lives in `daily/day-NN.md` and contains:

1. **5+ Probability & Expected-Value questions** — the kind that show up in S&T interviews.
2. **1 Brainteaser** — logic / lateral-thinking, as a closer.
3. **A Black-Scholes lesson** — one step along the course in `curriculum/black-scholes-syllabus.md`.
4. **A short quiz** on that day's lesson.
5. **All answers at the very end**, with slight explanations — so you can try everything cold first.

Every **3rd day** (Day 3, 6, 9, …) the quiz is a **bigger cumulative review** covering the prior lessons.

**Phase 1 (Days 1–15):** the Black-Scholes core — ✅ complete.
**Phase 2 (Day 16+):** two parallel tracks each day — **Track G (generalist sales & trading)** and **Track D (volatility trading / derivatives)** — see `curriculum/phase2-syllabus.md`. Daily prob/EV + brainteaser continue.

## How to use it

- Open the day's file, work top-to-bottom, and **don't scroll to the Answers section** until you're done.
- Time yourself on the prob/EV questions — interviewers care about speed and clean reasoning, not just the number.
- Track where you are in `progress.md`.

## Structure

```
README.md                                    <- you are here
progress.md                                  <- which day you're on, scores, notes
curriculum/black-scholes-syllabus.md         <- the full BS learning path
daily/day-01.md                              <- Day 1 content
daily/day-02.md                              <- (generated next)
...
quizzes/options-comprehensive-quiz-1.md      <- standalone big review quizzes
```

## Standalone review quizzes (`quizzes/`)

Beyond the built-in every-3rd-day quizzes, `quizzes/` holds larger cross-cutting reviews.
`options-comprehensive-quiz-1.md` covers Days 1–11 (fundamentals, pricing, all the Greeks
including vega and rho/dividends) **plus interview-style questions on options strategies**
(spreads, straddles, skew, and more) — with an answer key that explains each strategy.
